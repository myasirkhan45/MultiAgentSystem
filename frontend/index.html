About ResearchOS

      
ResearchOS coordinates a small team of specialized AI agents to turn a single research question into an evidence-backed report.

      
    
        
  • Search Agent — finds relevant sources across the web.
    • 
        
  • Reader Agent — scrapes and reads the selected sources.
    • 
        
  • Writer Agent — synthesizes findings into a structured report.
    • 
        
  • Critic Agent — scores the report and flags gaps.
    • 
      

      
Connect your own backend by editing CONFIG.API_URL in script.js.
